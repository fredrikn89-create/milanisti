# Format for innlegg på X (@milanistinet)

Engelsk tekst, kategori først, deretter tittel, så tre lenker uten https:

```
Perspective: Milan was Milan before anyone said Yankees

🇬🇧 milanisti.net/#s-yankees
🇳🇴 milanisti.net/no/#s-yankees
🇮🇹 milanisti.net/it/#s-yankees
```

- Kategori og tittel er `badge` og `title` fra `discord/queue.json` (engelsk).
- Lenkene er `#<id>` på milanisti.net, milanisti.net/no/ og milanisti.net/it/.
- Posting skjer foreløpig manuelt, med varsel om nye artikler.
